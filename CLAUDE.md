# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository purpose

Documentation-only repository. The sole content is `README.md`, a Norwegian-language student guide ("Veiledning for studenter") explaining how to:

1. Fork a GitHub exercise repository.
2. Open it in GitHub Codespaces.
3. Commit and sync changes back to their fork.

The repository is meant to be used itself as the example repo that students fork while following the guide ("Hvis dette er din første øving - kan du gjerne bruke dette repositoryet som et eksempel!").

## Working in this repo

- There is no build system, no tests, no source code, no dependencies. Do not invent commands.
- All content is in Norwegian (Bokmål). Preserve the language and tone when editing `README.md`; do not translate or rewrite sections into English unless explicitly asked.
- The README references an external image hosted on `github.com/user-attachments/...`. Leave that link intact.
- Step numbering and the **VIKTIG** ("IMPORTANT") callouts are load-bearing for students following along — keep the structure when editing.
